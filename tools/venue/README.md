# Venue data

`site/kino/venue.json` is the Kinepolis Antwerp venue model from
[Ghost Light](https://github.com/LoMagnette/ghost-light) by Loïc Magnette (MIT, see
`site/kino/THIRD_PARTY.md`): rooms, walls, seats, stairs and signs in metres, measured from the
Devoxx floor plans. It is generated by running their `src/venue/kinepolis.ts`, which is pure data:

```sh
git clone --depth 1 https://github.com/LoMagnette/ghost-light /tmp/ghost-light
sed "s#GHOST_LIGHT#/tmp/ghost-light#g" tools/venue/dump.mjs > /tmp/dump.mjs
npx esbuild@0.24.2 /tmp/dump.mjs --bundle --platform=node --format=esm \
  --alias:@=/tmp/ghost-light/src --outfile=/tmp/dump.bundle.mjs
node /tmp/dump.bundle.mjs | python3 tools/venue/compact.py > site/kino/venue.json
```
